# VK & Яндекс.Музыка — десктоп-плеер

Десктоп-приложение (Electron + React + TypeScript), которое держит VK Музыку и
Яндекс.Музыку в одном тёмном окне и показывает мини-плеер поверх всех окон,
когда приложение свёрнуто в трей.

Оформление собрано по вайрфрейму из `design/Wireframes.dc.html` — тёмная тема
`#121212`/`#1E1E1E`, акцент `#4A6CF7`, бейджи сервисов VK/YA.

## Как это устроено

Вход в сервис выполняется **на настоящем сайте внутри приложения** — логин и
пароль приложение не видит и не хранит. Каждый сервис живёт в своём
`WebContentsView` с отдельным `partition`, так что сессии не пересекаются и
переживают перезапуск.

Приложение не реализует плеер заново. В каждую вью инжектится адаптер
(`src/preload/service.ts`), который читает состояние проигрывателя сервиса
(`<audio>` + `navigator.mediaSession`) и выполняет команды нажатием на
собственные кнопки сервиса — очередью по-прежнему управляет сам сервис.
Селекторы вынесены в `src/preload/adapters/`; если сервис поменяет вёрстку,
недоступная команда просто гасит кнопку, а не ломает приложение.

Главный процесс — единственный владелец состояния воспроизведения и рассылает
его в шелл, мини-плеер и трей.

## Мини-плеер

Четыре варианта из вайрфрейма, переключаются в настройках (там же живое превью):

| Вариант | Размер | Описание |
| --- | --- | --- |
| Плашка | 384×80, 384×116 раскрытая | Минимум места, всё на виду |
| Карточка | 272×380 | Обложка крупно, прогресс, альбом |
| Пилюля | 230×48 → 330×82 | Самая компактная, раскрывается по наведению |
| Обложка | 264×264 | Квадрат с обложкой, контролы на затемнении |

Окно `frameless` + `transparent` + `alwaysOnTop('screen-saver')`, поэтому видно
и поверх полноэкранных приложений. Рендерер измеряет свой контент и сообщает
размер главному процессу — окно облегает содержимое и не перехватывает клики
пустотой.

Положение: пресеты углов и краёв экрана + отступ + выбор дисплея, либо своё
место — перетащите окно мышью, координаты сохранятся. При раскрытии окно растёт
внутрь экрана, а не за его край.

## Запуск

```bash
npm install
npm run dev     # разработка
npm run build   # сборка
npm run dist    # установщик NSIS для Windows
```

> В окружении расширения VS Code выставлена переменная `ELECTRON_RUN_AS_NODE=1`,
> из-за которой Electron стартует как обычный Node и падает на `app` is
> undefined. Запускайте из обычного терминала либо снимайте её:
> `env -u ELECTRON_RUN_AS_NODE npm run dev`.

## Горячие клавиши

Медиаклавиши play/pause, next, prev и `Ctrl+Shift+M` для мини-плеера. Работают,
когда приложение не в фокусе. Занятую другой программой комбинацию приложение не
перехватывает — в настройках она помечается «занята».
